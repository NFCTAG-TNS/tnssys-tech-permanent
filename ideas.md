# TNSSYS.TECH Permanent Website — Design Direction

## Ground-truth reference
This project migrates the existing TNSSYS.TECH website package into a permanent Manus WebDev project. The supplied package is the visual and structural source of truth: dark Sydney systems aesthetic, cyan and electric-blue accents, technical typography, infrastructure-focused messaging, and the Jotform voice agent embedded directly below the homepage hero.

## Design Movement
**Technical editorial / cyber-infrastructure brutalism.** The interface treats enterprise technology as an operational system: dense enough to feel credible, but organized with editorial hierarchy, strong contrast, and restrained motion.

## Core Principles
1. **Operational clarity:** headings, navigation, and actions should read like clear system controls.
2. **Dark depth with precise signal colors:** blue-black surfaces provide calm authority while cyan and electric blue indicate active states.
3. **Structured asymmetry:** sections use split panels, offset cards, and wide embedded tools rather than generic centered stacks.
4. **Trust through restraint:** animation, glow, and texture support hierarchy without becoming decorative noise.

## Color Philosophy
The visual field is built from deep navy and graphite surfaces that imply secure infrastructure. Cyan represents intelligence and clarity; electric blue represents action and connection. Green is reserved for live/operational states.

## Layout Paradigm
A persistent technical shell frames an editorial landing page: a fixed header, atmospheric hero, wide embedded scheduling agent, then modular systems sections and a compact footer. The scheduling agent is treated as a primary operational surface, not a button or popup.

## Signature Elements
- A Sydney harbor systems backdrop with a subtle telemetry/star field.
- Thin cyan/electric-blue borders and restrained glow around operational cards.
- Monospace micro-labels such as status, core focus, and agent-online indicators.

## Interaction Philosophy
Interactions should feel immediate and deliberate. Buttons use short, tactile transitions; navigation changes scroll smoothly; the appointment agent remains visible and usable in the page flow without requiring a new window.

## Animation
Use short fade-and-rise entrances, subtle hover translation, and active-state scale feedback. Respect reduced-motion preferences and avoid persistent attention-grabbing loops except for the small live-status indicator.

## Typography System
Use a bold geometric display face for major headings and a readable sans-serif for body copy, with monospace for operational labels and metadata. Preserve strong uppercase treatment for primary system headings.

## Brand Essence
**Titanium Solutions engineers resilient IT infrastructure and practical AI systems for organizations that need technology to stay operational under pressure.** Personality: precise, assured, forward-looking.

## Brand Voice
Headlines are concise and systems-oriented. CTAs are direct and action-led. Microcopy sounds like an operations console rather than generic marketing.

Example lines:
- “We engineer systems that prevent downtime.”
- “Speak with the Appointment Request Agent to secure an engineering consultation slot.”

## Wordmark & Logo
Use the existing TNSSYS.TECH wordmark treatment with a compact geometric titanium-style system mark at the left. The symbol should remain legible at header and favicon sizes without relying on text.

## Signature Brand Color
**Signal Cyan — #22D3EE.** It is the recognizable active-state color across the brand, used sparingly for focus, intelligence, and live system feedback.
